# libSCT

[English](README.md) | **Русский**

**Нативная библиотека для модификации Plants vs. Zombies 2.**

`libSCT` — нативная библиотека на C++, содержащая модификации игровой механики и исправления для Plants vs. Zombies 2. Она рассчитана на **оригинальный билд игры 9.6.1** и использует жёстко заданные адреса функций и оффсеты памяти.

Исходный код и отдельные модули можно свободно использовать, изменять и интегрировать в другие проекты. Указывать автора не требуется.

## Возможности

- **PassDamage Armor** — модифицированное поведение брони зомби с настраиваемым взаимодействием со снарядами.
- **Umbrella Leaf** — изменённое поведение растения, включая обнаружение и отражение снарядов.
- **Quest Rewards Fix** — исправление иконок растений в интерфейсе наград за задания.
- **Lawn Zoom Fix** — изменение поведения масштабирования газона.

## Совместимость

**Поддерживается только оригинальный билд Plants vs. Zombies 2 версии 9.6.1.**

Адреса функций и оффсеты памяти жёстко заданы для конкретного бинарного файла игры. Библиотека не определяет их автоматически посредством поиска сигнатур или шаблонов в памяти.

Другие версии игры не поддерживаются. Для переноса на другой билд потребуется определить соответствующие адреса и оффсеты, адаптировать затронутые хуки и заново протестировать модификации.

## Установка

`libSCT` загружается как нативная динамическая библиотека Android. Ниже описан один из способов интеграции в модифицированный APK.

### 1. Распакуйте APK

Используйте любой подходящий инструмент для редактирования APK. Например, [APKLab](https://github.com/APKLab/APKLab) для Visual Studio Code.

### 2. Добавьте библиотеку

Поместите `SCT.so` в каталог нативных библиотек APK:

```text
lib/arm64-v8a/SCT.so
```

APK и целевая среда должны поддерживать архитектуру ARM64.

### 3. Добавьте вызов загрузки библиотеки

Откройте файл:

```text
smali_classes2/com/popcap/PvZ2/PvZ2GameActivity.smali
```

Найдите код загрузки оригинальной библиотеки игры:

```smali
const-string v0, "PVZ2"
invoke-static {v0}, Ljava/lang/System;->loadLibrary(Ljava/lang/String;)V
```

Сразу после него вставьте:

```smali
const-string v0, "SCT"
invoke-static {v0}, Ljava/lang/System;->loadLibrary(Ljava/lang/String;)V
```

Это заставит Android загрузить `SCT.so` после `libPVZ2.so`.

### 4. Пересоберите APK

Пересоберите и подпишите APK привычным вам инструментом, затем установите его в совместимую среду.

Если игра не запускается, проверьте расположение библиотеки, архитектуру, зависимости и системные логи.

## Сборка

### Требования
- Android NDK r27d
- CMake
- Ninja

Проект можно собрать в Windows или другой поддерживаемой среде с помощью CMake и Android NDK.

Результат сборки: `SCT.so` для архитектуры `arm64-v8a` с целевой платформой Android API 26.

### Компиляция

Настройте проект с использованием Android NDK:

```bash
cmake -S . -B build -G Ninja \
  -DCMAKE_TOOLCHAIN_FILE=/path/to/android-ndk/build/cmake/android.toolchain.cmake \
  -DANDROID_ABI=arm64-v8a \
  -DANDROID_PLATFORM=android-26 \
  -DOBBY_GENERATE_SHARED=OFF
```

Соберите библиотеку:

```bash
cmake --build build
```

Выходная библиотека называется `SCT.so`. Её точное расположение зависит от конфигурации сборки.
